# TimeCraft 

A responsive watch-shopping website inspired by Casio's watch collections.

##  Live Website

**Visit TimeCraft:** https://timecraft-store.netlify.app/

##  Features

- Responsive layout for desktop, tablet, and mobile screens
- Watch collection and promotional sections
- Search and navigation interactions
- Product gallery and interactive elements

##  Built With

- HTML5
- CSS3
- JavaScript

##  Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

If you use VS Code, you can also run the project with the Live Server extension.

## Project Structure

```text

├── index.html

```
